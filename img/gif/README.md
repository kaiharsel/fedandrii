# Записи прокрутки для кейсів

Сюди кладуться гіфки. Поки файла немає, блок на сторінці просто не
показується, тож нічого не ламається - можна додавати по одному.

Імена фіксовані, змінювати не треба:

| Файл | Що знімати |
|---|---|
| melume-home.gif | Melumé: головна, прокрутка згори вниз |
| melume-catalog.gif | Melumé: каталог і фільтри |
| melume-product.gif | Melumé: сторінка товару |
| velvet-home.gif | VelvetCake: головна, прокрутка згори вниз |
| velvet-catalog.gif | VelvetCake: каталог і форма заявки |
| velvet-crm.gif | VelvetCake: CRM, список заявок |

Ширина від 1200 px, 10-15 секунд. Гіфка такої довжини важить 10-30 МБ -
це багато для сторінки. Якщо вийде важка, скажи: перероблю блоки під mp4,
те саме відео важитиме 1-2 МБ і виглядатиме чіткіше.
