About the project

Task

The idea for the app existed, but not the answer to how a person would actually use it: which steps they take, where they get stuck and what they see on each screen

Solution

Started from user flows in FigJam, broke the paths into steps and only then drew screens. Every screen solves one job, and the transition logic is written down for the developers

Project screens

Home screen Feed and quick actions
Product page Details and the action button
User flow From sign-in to the goal
